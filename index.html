HOW TO PUSH TO GITHUB & RUN LOCALLY

1. Push to GitHub Repository (Terminal Commands):
Extract the downloaded ZIP file into a folder and run: 

git init -b main
git add .
git commit -m "Deploy Puchakayala Jeevan portfolio website"
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git push -u origin main

2. Enable Free Hosting on GitHub Pages:
In your GitHub repository, open Settings → Pages, select Deploy from a branch → main → / (root), and click Save. Your live website will be published at https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/.

3. Folder Structure & Local Server: 

portfolio/
├── index.html
├── README.md
└── assets/
    ├── profile-studio.png
    └── aistudio/ (53 widescreen sequence frames)

# Run locally with Python:
python -m http.server 8000
